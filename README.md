# Синхронизация потоков ОС (Алгоритм Деккера | Читатели и Писатель)

Графическое Win32-приложение для демонстрации механизмов синхронизации потоков:

1. **Алгоритм Деккера** — программное взаимное исключение двух параллельных вычислительных потоков ($Y = x^2 / 18$ и подсчёт суммы $Z$).
2. **Задача «Читатели и Писатель»** — синхронизация с помощью критических секций Windows API (`EnterCriticalSection` / `LeaveCriticalSection`) с приоритетом писателя, плавной 60 FPS анимацией и гибкой настройкой частоты/скорости.

---

## Запуск проекта из GitHub

### Шаг 1. Клонирование репозитория

Откройте терминал и выполните:

```bash
git clone https://github.com/blu6i/os-thread-sync.git
cd os
```

---

### Шаг 2. Сборка и запуск

Сборка выполняется одной командой:

```bash
make run
```

---

## Системные требования

- **Операционная система**: Windows 7 / 8 / 10 / 11 (x86 / x64)
- **Компилятор**: MinGW GCC с поддержкой C11
- **Графические библиотеки**: Win32 GDI, Common Controls, GDI+ (стандартные библиотеки Windows, установка дополнительных пакетов не требуется)

---

## Доступные команды Makefile

| Команда | Описание |
|---|---|
| `mingw32-make run` | Собрать проект (при необходимости) и запустить приложение |
| `mingw32-make` | Собрать проект в режиме Release с оптимизацией (`-O2`) |
| `mingw32-make rebuild` | Полностью очистить артефакты и пересобрать с нуля |
| `mingw32-make clean` | Удалить каталог `build/` и все скомпилированные файлы |
| `mingw32-make map` | Сгенерировать карту проекта и аудит Doxygen в каталоге `docs/` |
| `mingw32-make DEBUG=1` | Собрать проект с отладочными символами (`-g -O0`) |
| `mingw32-make help` | Вывести справку по доступным целям |
